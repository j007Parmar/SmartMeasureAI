# SmartMeasure AI 🔭

> AI-Powered AR Construction Measurement Platform

## Features
- AR Room Scanner Simulator
- AI Measurement Engine
- Construction Calculator (tiles, paint, cement, bricks)
- Professional PDF/Excel/CSV/JSON Export
- Futuristic Holographic UI

## Tech Stack
- React 18
- Framer Motion
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Deploy to Vercel
1. Push to GitHub
2. Import repo on vercel.com
3. Click Deploy
